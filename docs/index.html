L'APPLICATION

Un laboratoire et un moteur de décision.

Toutes les étapes clés de l'étude sont reliées dans un même espace Streamlit, avec une API FastAPI et des expériences ML enregistrées indépendamment.

01 / DATA

Dashboard & EDA

Montants, tendances, catégories, caractéristiques temporelles, distributions et exploration par filtres.

02 / MODELS

ML Laboratory

Entraînements Train/Validation, hyperparamètres ajustables, Logistic Regression, RF, XGBoost, Isolation Forest et Autoencoder.

03 / EVALUATION

Model Comparison

PR-AUC, ROC-AUC, métriques et comparaisons identifiées par modèle, partition et provenance.

04 / STRATEGY

Risk Simulator

Scénarios seuil/budget, coût d'alertes, fraudes manquées et contraintes chronologiques.

05 / LIVE

Transaction Tester

Prédiction de référence V2 ou expérience enregistrée, sans modifier la politique opérationnelle.

06 / TRUST

Alert Center & XAI

Quotas quotidiens atomiques, suivi des alertes et facteurs explicatifs SHAP.

MÉTHODOLOGIE

Évaluation sans fuite temporelle.

Le protocole distingue les décisions scientifiques des opérations : données Train pour apprendre, Validation pour sélectionner, Test figé pour le bilan final.

Transactions brutes→15 features causales→Train 60 % / Val 20 %→Coût métier→RF V2 figé

Seuil de référence : 0,22266507475921693. Scores non calibrés comme probabilités. Les modèles expérimentaux ne remplacent pas automatiquement le modèle V2.
